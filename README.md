## 🏛 Архитектура системы

Система состоит из 3 независимых микросервисов, API Gateway и отдельных экземпляров баз данных PostgreSQL для каждого сервиса.

```
                        ┌────────────────────────┐
                        │      API Gateway       │
                        │        (Nginx)         │
                        └───────────┬────────────┘
                                    │
           ┌────────────────────────┼────────────────────────┐
           ▼                        ▼                        ▼
┌────────────────────┐   ┌────────────────────┐   ┌────────────────────┐
│   User Service     │   │   Movie Service    │   │  Booking Service   │
│   (Port: 8001)     │   │   (Port: 8002)     │   │   (Port: 8003)     │
└──────────┬─────────┘   └──────────┬─────────┘   └──────────┬─────────┘
           │                        │                        │
     [ DB: users ]            [ DB: movies ]           [ DB: bookings ]
```

### 2. Movie Service (Сервис фильмов и сеансов)
* **Назначение:** Хранение каталога фильмов, залов и расписания сеансов.
* **База данных:** PostgreSQL (`db_movies`)

#### Модели данных:
* **Movies:** `id`, `title`, `description`, `duration`, `age_limit`
* **Halls:** `id`, `name`, `total_seats`
* **Shows (Сеансы):** `id`, `movie_id` (FK), `hall_id` (FK), `start_time`, `price`

#### Эндпоинты:
* `GET /api/v1/movies` — Список всех фильмов.
* `GET /api/v1/movies/{id}` — Детальная информация о фильме.
* `POST /api/v1/halls` — Создать зал *(только ADMIN)*.
* `GET /api/v1/halls` — Посмотреть зал *(только ADMIN)*.
* `POST /api/v1/movies` — Добавить фильм *(только ADMIN)*.
* `GET /api/v1/shows?date=YYYY-MM-DD` — Получить расписание сеансов.
* `GET /api/v1/shows/{id}` — Получить детали сеанса и базовую информацию о зале.
